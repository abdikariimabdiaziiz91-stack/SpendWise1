SpendWise - Budget Tracker

Project Description

SpendWise is a simple budget tracking application that helps users manage their money, record expenses, and monitor their remaining balance.

Features

Set a personal budget.
Add expenses with names and amounts.
View total budget.
View total expenses.
Calculate remaining balance automatically.
Delete expenses.
Validate user input.
Display helpful messages.

Deployment Process

Created the SpendWise project files in GitHub.
Connected the GitHub repository to Netlify.
Selected the main branch for deployment.
Enabled automatic publishing from the main branch.
Netlify provides a live website for the project.
Challenges Encountered
